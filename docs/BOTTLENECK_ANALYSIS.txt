RISK FACTORS:
=============

1. Parallel API Calls
   ├─ Issue: More concurrent OpenAI API calls
   ├─ Cost: Higher (but same tokens total)
   ├─ Rate limit: Monitor for 429 Too Many Requests
   └─ Fix: Use exponential backoff retry

2. Quality Without Validation
   ├─ Issue: No fact-checking, may have errors
   ├─ Impact: ~10-20% of quizzes might be factually wrong
   ├─ Mitigation: Accept lower accuracy or implement periodic audits
   └─ Alternative: Use batch validation instead

3. File I/O Concurrency
   ├─ Issue: Multiple threads writing JSON files
   ├─ Impact: File corruption if not protected
   ├─ Fix: Use threading.Lock() for JSON writes
   └─ Code change: 3-5 lines in quiz_batch.py

4. Memory Usage
   ├─ Issue: 4 threads × 150KB per thread = 600KB extra
   ├─ Impact: Minimal (modern systems have GBs)
   ├─ Fix: None needed
   └─ Status: Not a concern
