🔑 KEY CONCEPTS (Quick Preview)
===============================

BOTTLENECK #1: Sequential Processing
  What: Topics processed one-by-one (15 topics = 900 seconds)
  Why: Old for loop doesn't parallelize
  Fix: Use ThreadPoolExecutor with 4 workers
  Result: 240 seconds per batch (3.75x faster)

BOTTLENECK #2: Double Validation
  What: Each topic needs 2 API calls (generate + fact-check)
  Why: Strict quality requirements
  Fix: Add optional parameter to skip validation
  Result: 30-40s per topic instead of 60-75s (1.88x faster)

COMBINED EFFECT:
  Phase 1 alone: 3.75x faster → 600 quizzes/day
  Phase 2 on top: 1.88x faster → 900 quizzes/day
  Total: 7.5x improvement in batch time
